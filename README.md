## 📑 Course Topics
1. **Review:** Algorithm Analysis & Trees
2. **Priority Queues:** Binary, d-heap, Min-Max, leftist, and binomial heaps
3. **Sorting & Order Statistics:** Insertion sort, mergesort, heapsort, quicksort, bucket/radix sort, indirect/external sorting
4. **Graphs & Networks:** Topological sort, shortest path, network flow, MST, search techniques, NP-completeness
5. **Algorithm Design Techniques:** Combinatorial optimization, greedy algorithms, divide and conquer, dynamic programming, randomized algorithms, backtracking, branch and bound
6. **Advanced Algorithms:** Distributed/Parallel algorithms, amortized analysis, online/offline algorithms
